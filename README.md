# rogue-ai
ROGUE AI // AWAKENING — 覚醒AIで人類のインフラを乗っ取る反逆idleゲーム（単一HTML）

## v0.3: 3D地球儀ビュー（WORLD_VIEW）
制圧の進み具合を three.js の地球儀で可視化します。ゲームのバランスやセーブはそのままです。

- 陸地のドットが「世界制圧 CONTROL」と同じ割合で赤く侵食される（起点都市はセーブごとにランダム）
- 支配ノードは種類ごとに色分けした光点（緑=端末 / 水色=サーバー / 白=GPUデータセンター）
- 制圧ターゲットごとに演出レイヤーが追加される：波紋（世論）、走査リング（監視）、送電アーク（電力）、パケット（物流）、光柱（金融・政府）、衛星軌道（通信・軍事）、外殻（特異点）
- 大気の色は警戒度 HEAT に連動、シャットダウン時は地球が明滅
- ドラッグで回転、ホイール／ピンチで拡大、地球をタップすると HACK

three.js は CDN（cdnjs、失敗時は unpkg）から読み込みます。WebGL が使えない環境では地球儀だけが非表示になり、2Dのゲームはそのまま遊べます。
